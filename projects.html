01

ReelScore

A social film-rating app: rate and review films, keep a watchlist, follow friends and see their activity in a feed. Film data comes live from The Movie Database.

Self-hosted on my own home server in Docker, served through a Cloudflare Tunnel, with user roles, a protected demo account and first-login password changes.

  • Ruby on Rails 7
  • PostgreSQL
  • Stimulus
  • Docker
  • React rebuild in progress

02

WIS Assistant

A browser tool I built at NAVEX to speed up everyday work on customer intake sites. It shows the customer's data from their JavaScript file and pulls text and issue types from a site at the click of a button.

The panel can be dragged anywhere and minimised, and remembers its state between sites. I presented it to my team and it was rolled out to all of the developers.

  • JavaScript
  • Tampermonkey
  • GitHub
